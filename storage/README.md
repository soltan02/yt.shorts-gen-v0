# Storage Directory

This folder holds local runtime data for ViralClip AI Studio.

## 🔒 Confidentiality Notice
All files generated in this folder (downloaded videos, rendered shorts, OAuth tokens, and SQLite database) are **strictly gitignored** and will never be committed to Git.

## 🔑 YouTube 1-Click Publishing Setup
To enable 1-click uploads to your YouTube channel:
1. Download your OAuth 2.0 `client_secret.json` from Google Cloud Console.
2. Place it in this folder (`storage/client_secret.json`).
3. Connect your channel in the **Settings** tab.
